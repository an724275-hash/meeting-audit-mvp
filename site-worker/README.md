# Опубликованная версия

Это исходники версии на https://royal-brick-meeting-audit-ave.woolly-fairy-9894.chatgpt.site/. Серверная часть написана как Cloudflare Worker; интерфейс и пример промпта лежат рядом. Для сборки нужен Node.js:

```sh
node scripts/build.mjs
node scripts/test.mjs
```

Сборка создаёт `dist/server/index.js`. На публичном сайте доступен только режим OpenAI API. Посетитель вводит свой ключ; сервер передаёт его в OpenAI вместе с аудио или текстом и не сохраняет. Ограничение аудиофайла на опубликованной версии: 4 МБ. Промпт заказчика и записи встреч сюда не включены.
